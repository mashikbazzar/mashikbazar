- **প্যাকেজে সব পণ্যের তালিকা থেকে যোগ করা যায়** (খুঁজে + যোগ করুন / মুছুন); প্যাকেজের আইটেম মুছাও যায়।
- **কাস্টমার লগইনের আগে দাম দেখবে না** — শুধু নাম ও ব্র্যান্ড। লগইন করলে দাম দেখা যায় (অ্যাডমিন এক ক্লিকে দাম চালু/বন্ধ করতে পারে: পণ্য ট্যাবে "কাস্টমারের দাম" বোতাম)।
