## ফাইল

- `index.html` — পুরো অ্যাপ (এক ফাইলে)
- `products.json` — ১৩৩ পণ্য + ৩ প্যাকেজের ডেটা
- `manifest.webmanifest` — ফোনে অ্যাপ হিসেবে রাখার সেটিং

## নোট

- দামগুলো দোকানের শুরুর দাম। পাইকারি দাম যাচাই করে দাম বদলাতে পারে।
- ডেলিভারি চার্জ এখনো ঠিক হয়নি, তাই আপাতত ৳০ ধরা আছে।
- এই সংস্করণে অর্ডার সেভ হয় না — অর্ডার WhatsApp-এ যায়।

## অ্যাডমিন প্যানেল

অ্যাপের নিচে **অ্যাডমিন** ট্যাব আছে — প্রথমবার নিজের PIN বসান। সেখানে দাম, পণ্য, ডেলিভারি চার্জ, WhatsApp নম্বর বদলে **প্রকাশ করুন** চাপলে GitHub-এ সরাসরি যাবে, Muse-এ ফিরতে হবে না। প্রকাশ করতে GitHub টোকেন লাগে (অ্যাডমিন প্যানেলেই বানানোর উপায় লেখা আছে); টোকেন শুধু আপনার ফোনে থাকে।
